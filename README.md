# Coupon Campaign & GP Anomaly Dashboard 📊🎟️

แดชบอร์ดติดตามและวิเคราะห์แคมเปญคูปอง ยอดขาย และเฝ้าระวังบิลขายต่ำกว่าทุน (GP ติดลบ) อัตโนมัติ  
ดึงข้อมูลจากระบบฐานข้อมูล `MYPOS2018_CENTER` ตลอด 206 สาขา (ยกเว้นคลังส่วนกลาง 901)

---

## 🌟 ฟังก์ชันหลัก (Core Features)

1. **🎟️ วิเคราะห์คู่บิลคูปอง (Coupon Pairs Analysis)**
   - จับคู่ **บิล 1 (บิลที่ได้คูปอง)** เทียบกับ **บิล 2 (บิลที่นำคูปองมาใช้)**
   - ตรวจจับพฤติกรรมแยกบิลซื้อซ้ำทันที (Split Bill within 10 mins)
   - คำนวณยอดขายรวม ต้นทุนรวม กำไรสุทธิรวม (Combined Net GP) และอัตรากำไร (% Net Margin)
2. **🚨 เฝ้าระวังบิลขายติดลบ (Live GP Anomaly Alert)**
   - สรุปภาพรวมรายภาค Drill-down ถึงระดับสาขาและรายบิล
   - แจ้งเตือนบิลที่เสี่ยงขายต่ำกว่าทุนและสรุปสาเหตุเชิงลึก (Root Cause Analysis)
3. **📅 ขอบเขตข้อมูล (Data Scope)**
   - ข้อมูลสะสมตั้งแต่ **1 พฤศจิกายน 2026 ถึง ปัจจุบัน**
   - มีตัวกรองดูข้อมูลสะสมทั้งแคมเปญ หรือเจาะลึกเฉพาะแต่ละวัน
4. **⚡ Auto-update ทุก 20 นาที บน Cloud (GitHub Actions)**
   - ดึงข้อมูลและอัปเดตหน้าเว็บอัตโนมัติ 24 ชม. ผ่าน GitHub Actions แม้ปิดเครื่องคอมพิวเตอร์
   - เผยแพร่ผ่าน GitHub Pages เปิดดูได้ทุกที่บนมือถือและคอมพิวเตอร์

## ⚙️ การตั้งค่า GitHub Actions & Secrets

เพื่อความปลอดภัย กรุณาตั้งค่า **Repository Secrets** ใน GitHub (`Settings` > `Secrets and variables` > `Actions`):

| Secret Name | คำอธิบาย |
| :--- | :--- |
| `DB_HOST` | Hostname / IP ฐานข้อมูล MySQL |
| `DB_PORT` | พอร์ตเชื่อมต่อ (เช่น 13306) |
| `DB_USER` | ชื่อผู้ใช้ฐานข้อมูล |
| `DB_PASSWORD` | รหัสผ่านฐานข้อมูล |
| `DB_NAME` | ชื่อฐานข้อมูล (`MYPOS2018_CENTER`) |
